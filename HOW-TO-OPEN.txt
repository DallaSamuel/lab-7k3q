PipFrame prototype (private, not for sharing yet)

1. Unzip this folder.
2. Open a terminal in the folder and run:  python -m http.server 8765
3. Open http://localhost:8765 in Chrome, Edge or Brave. Double-clicking index.html works for a quick look, but the Install button needs the address above.

Test files in this folder (all made up):
- sample-mt5-report.html : Journal > Import report
- sample-backup-150-FAKE-trades.json : Settings > Restore (fills the Review screen)
- Or skip files: Settings > Demo data > Add demo (40 made-up trades, removable)

Run the importer tests:  node --test

If you edit index.html: run  python seal.py index.html  afterwards (it updates the security policy hashes), then  node --test  to confirm.
